# 테아프셉의 바다 — 드림 200일 축하 홈페이지

글·편지·영시·그림을 올리면 **Netlify Blobs**에 저장되는 사이트예요. (별도 데이터베이스 없음)

## 폴더 구성
- `public/index.html` — 화면 전체 (맨 위 `CONFIG`에서 사이트 제목·시작일 등을 바꿔요)
- `netlify/functions/api.mjs` — 비밀번호 확인, 글 저장·수정·삭제, 이미지 저장 (서버 쪽)
- `netlify.toml`, `package.json` — Netlify 설정

## 올리는 방법 (GitHub 연결)
> 서버 함수가 `npm install`을 필요로 해서, 폴더 끌어다 놓기(드래그 앤 드롭)가 아니라 **GitHub 연결 방식**으로 올려 주세요.

1. 이 폴더 전체를 새 GitHub 저장소에 올려요.
2. Netlify → **Add new site → Import an existing project** → 그 저장소를 골라요. (Build command는 비워 두고, 나머지는 `netlify.toml`이 알아서 채워요.)
3. Site configuration → Environment variables에 아래를 등록해요.

| 이름 | 뜻 | 예시 |
|---|---|---|
| `SESSION_SECRET` | 로그인 쿠키를 서명하는 비밀 문자열 (필수, 길게 아무거나) | `x8Kq2mZ...` (30자 이상) |
| `SITE_PASSWORD` | 처음 들어올 때 비밀번호 (선택, 안 넣으면 `0505`) | `0505` |

4. 등록 후 **Deploys → Trigger deploy**로 다시 배포해요.
5. 다른 분께 다시 쓰고 싶을 때는 `public/index.html` 맨 위 `CONFIG`의 `siteTitle`(제목)과 `startDate`(시작일, 이 날이 1일째)만 바꾸면 돼요.

## 쓰는 법
- **들어가기**: 처음 접속하면 비밀번호 네 자리(0505)를 입력해요. 30일 동안 기억해요.
- **글·그림 올리기**: 닉네임, 제목, 내용, (이미지), **글 비밀번호**를 입력해요. 그 글을 고치거나 지울 때 이 비밀번호가 필요해요. 비밀번호는 암호화해서 저장해서 주인도 볼 수 없어요.
- **꾸미기·곡 추가**: 입구 비밀번호로 들어온 사람은 누구나 할 수 있어요.
  - 왼쪽 아래 **꾸미기** 버튼: 배경 이미지, 장식 이미지(끌어서 위치 이동, 크기 조절), 배경 어둡게 덮기, 제목 글꼴, 카드 투명도, 포인트 색을 바꾸고 저장하면 **모든 방문자에게** 똑같이 보여요.
  - 플레이리스트 아이콘(≡) → **유튜브 영상 링크**를 붙여 넣어 곡을 추가·삭제해요. (재생목록 링크가 아니라 영상 하나의 링크)
  - **제목 글꼴**: 눈누(noonnu.cc)나 구글 폰트에서 **"웹폰트로 이용하기"** 코드를 복사해 꾸미기의 글꼴 칸에 붙여 넣고 [적용해 보기] → [저장하기]. 글꼴 이름은 보통 자동으로 찾고, 못 찾으면 이름 칸에 적어 주세요. 안전을 위해 글꼴 정의(`@font-face`)와 구글 폰트·jsDelivr 같은 글꼴 주소만 받아들이고 나머지 코드는 무시해요.
- **음악**: 방문자가 재생 버튼을 눌러야 시작돼요(브라우저 규칙). 유튜브가 퍼가기를 막아 둔 영상은 재생되지 않고 다음 곡으로 넘어가요.

## 알아 두면 좋은 점
- 이미지는 올릴 때 자동으로 줄여서 저장해요 (그림 최대 1600px, 배경 2200px).
- 비밀번호를 8번 틀리면 15분 동안 잠겨요.
- `0505`는 "초대받은 사람만 들어오는 문" 정도의 보호예요. 아주 민감한 내용은 올리지 말아 주세요.
- 저장된 글과 이미지는 다시 배포해도 사라지지 않아요.
- 내 컴퓨터에서 시험하려면: `npm install` 후 `npx netlify dev` (Netlify 로그인 필요)
